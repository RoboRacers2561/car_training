## Intentional behavior fix versus preserved problems

The old image-frame velocity function sliced a simulator tensor then flipped y
in place. Repeated observation/reward reads could modify cached simulator state.
The extracted implementation returns independent `(vx, -vy)` storage. This is an
intentional bug fix, so trajectory equivalence with the old baseline is not claimed.

Other numerical/model behavior was preserved, including unusual velocity axes,
nonzero driving minimum, tanh action mapping, contour-based rather than verified
centerline reward, obstacle reward gating, model BatchNorm initialization, and
the inherited image scaling. Characterization tests do not endorse these choices.

Pinned Isaac Lab 2.3 stores `_step_reward` as weighted values before dt; manager
reset leaves that step buffer intact. The telemetry integration was checked
against the actual pinned source. Its termination manager retains the last
configured matching cause, not all simultaneous causes; the manifest/docs say so.
